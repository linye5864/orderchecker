# OrderComparer V3 智能订单对账平台 - 界面设计文档（UI Design Spec）

**版本**：1.0  
**日期**：2026-01-19  
**适用范围**：Web（优先桌面端，兼容平板/移动端）  
**风格基线**：demo `demo/index-v2.html` + `demo/styles-v2.css`（professional v2.1）  
**规范来源**：`docs/ui/02-UI-UX交互规范.md`（uipro 原则：可访问性优先、150–300ms 过渡、focus-visible、no emoji icon、响应式四断点）

---

## 0. 设计目标与约束

### 0.1 设计目标
- **专业可信**：财务/对账工具应“克制、稳定、可审计”，避免花哨/情绪化。
- **高效率**：高频场景（上传、对账、定位异常、导出）尽量减少点击路径与视线移动。
- **一致性**：布局、组件、动效、文案、状态反馈在全站一致。
- **可访问性**：WCAG 2.1 AA；键盘可达；清晰焦点；对比度合规；尊重 reduced motion。

### 0.2 强约束（必须遵守）
- **禁止用 emoji 作为图标**：统一 SVG 图标（Heroicons/Lucide）。
  - 备注：demo 中存在 emoji icon（如导航/卡片/提示）；V3 设计要求替换为 SVG。
- **所有可交互元素必须有 hover/active/focus-visible 状态**，并具备 `cursor: pointer`。
- **动效时长**：150ms（轻反馈）/200ms（默认）/300ms（复杂组件）/400ms（页面切换）。

## 1. 设计系统（Design Tokens）

> 以 `demo/styles-v2.css` 的 `:root` 为基准，保持专业偏蓝体系。

### 1.1 色彩
- Primary：`--primary-50 ~ --primary-900`
- Neutral：`--gray-50 ~ --gray-900`
- Functional：`--success --warning --error --info`

使用规则：
- 表面（surface）默认白色 `#fff`；页背景 `--gray-100`；分割线 `--gray-200`。
- 交互高亮用 `--primary-600`，hover 用 `--primary-700`。
- 异常强调背景建议使用 `#fef2f2 / #fee2e2`（与 demo 一致）。

### 1.2 字体
- Sans：系统 UI 字体（或 Inter）
- Mono：用于订单号/金额等对齐字段（JetBrains Mono / Fira Code / Courier New）

字号建议：
- 页面标题 18px（与 demo topbar 一致）
- 区块标题 15–16px
- 正文 13px
- 辅助信息 11–12px

### 1.3 圆角/阴影/边框
- 圆角：`--radius-sm(4)` / `--radius-md(6)` / `--radius-lg(8)`
- 阴影：卡片 hover：`0 2px 8px rgba(0,0,0,0.06)`；重弹窗：`0 20px 25px -5px rgba(0,0,0,0.1)`
- 边框：`1px solid --gray-200`（默认）

### 1.4 动效
- 过渡：`var(--transition)`（demo 为 `0.2s ease`）
- 页面切换：400ms 淡入/上移（reduce motion 时禁用或缩短）

### 1.5 断点
- 375（Mobile）/ 768（Tablet）/ 1024（Desktop）/ 1440（Large）

## 2. 信息架构（IA）与全局框架

### 2.1 页面与导航
主菜单（与 demo 对齐）：
1) 工作台 Dashboard  
2) 文件上传 Upload  
3) 开始对账 Reconciliation Console（向导）  
4) 对账结果 Results  
5) 历史记录 History  

系统管理：
6) 平台配置 Platforms  
7) 数据大屏 Dataview  
8) 系统设置 Settings

### 2.2 App Shell（全局布局）
- 左侧 Sidebar：宽 220px；折叠 60px
- 顶部 Topbar：高 56px
- 内容 Content：padding 20px（`--space-xl`）

交互：
- Sidebar 折叠/展开：200ms（宽度/主内容 margin-left 同步）
- 移动端（<=768）：Sidebar off-canvas，出现遮罩层

### 2.3 全局状态建议（跨页面一致）
- Loading（按钮/区块/页面）
- Empty（空列表/无文件/无结果）
- Error（接口失败/校验失败）
- Toast 通知（success/error/warning/info；右上角 slide-in 300ms；可关闭）

## 3. 组件规范（核心组件库）

> 本节定义“长相 + 行为”，供前端/设计实现一致。

### 3.1 Button
- Primary：背景 `--primary-600`，hover `--primary-700`，active `--primary-800`
- Secondary/Outline：白底 + `--gray-300` 边框；hover `--gray-50/100`
- Size：
  - Default：padding 11×20，font 14
  - Small：padding 6×12，font 12

状态：
- Disabled：灰底 + not-allowed
- Loading：按钮内 spinner + 文案“处理中...”

### 3.2 Input / Select
- 高度约 34–36px（与 demo 8px padding 对齐）
- Focus：边框 `--primary-500` + 2–3px ring（`--primary-50`）

### 3.3 Card
- 白底 + `--gray-200` 边框
- Hover：边框 `--primary-200/300` + 轻阴影

### 3.4 Table
- Header：`--gray-50` 背景，`--gray-700` 文本
- Row hover：`--primary-50`
- Exception row：浅红底（与 demo）

### 3.5 Tabs
- 横向 tab，active 下划线 `--primary-600`
- Tab hover：背景 `--gray-50`

### 3.6 Stepper（对账向导）
- 4 步：active 主题色 + ring；completed 成功色
- 连接线：`--gray-200`

### 3.7 Modal
- overlay：半透明黑（建议 40%）
- 动效：200–300ms（scale/opacity）
- Esc 关闭、点击遮罩关闭（可配置）

### 3.8 Toast / Notification
- 右上角固定
- 左侧色条：success/error/warning/info
- 자동关闭：3–5s（可选）

### 3.9 Icon
- 统一 SVG，建议 Lucide 或 Heroicons（outline 风格）
- 尺寸：16/20/24/48

## 4. 页面级设计规范（逐页）

### 4.1 登录页（Login）
参考：demo `#loginPage`。

布局：左右分栏
- Left：品牌区 + 3 张 feature card（可滚动时保持居中）
- Right：登录表单（最大宽 380px）

关键组件：
- Username、Password、Remember checkbox、Forgot link
- 密码可见切换（使用 eye/eye-off SVG）

交互与状态：
- 提交：Primary loading
- 登录成功：toast success + 800ms 跳转
- 登录失败：表单 shake + toast error

可访问性：
- label 与 input 绑定
- 键盘 Tab 顺序：用户名 → 密码 → 记住我 → 忘记密码 → 登录

移动端（<=768）：隐藏左侧品牌区，仅显示右侧表单。

---

### 4.2 工作台（Dashboard）
参考：demo `#dashboard`。

组成：
1) 统计卡片 4 张（今日对账/成功/异常/金额）
2) 趋势图（canvas）+ 平台分布列表（进度条）
3) 待处理任务列表（3 条示例，含优先级标签）

交互：
- stat-card hover：边框变蓝 + 阴影（200ms）
- 平台分布条：进入页面后从 0 动画到目标宽度（1s，reduce motion 时禁用）
- 任务项 hover：背景从 `--gray-50` 变 `--gray-100`

空/异常：
- 若无任务：显示 EmptyState（说明 + 引导按钮）

---

### 4.3 文件上传（Upload）
参考：demo `#upload`。

布局：左右双栏
- Left（350px）：数据源（本地导入 + 自动化抓取源卡片）
- Right：文件池（pool header/body/footer）

关键交互：
- Dropzone：hover/drag-over 边框主题色 + 背景 `--primary-50`
- 文件项：slideIn 300ms（reduce motion 时禁用）
- 文件分类标签：配送/流水/平台（颜色遵循 demo：蓝/黄/紫）
- 文件池统计：实时更新“已就绪 X 个文件”
- “进入对账控制台”按钮：
  - 无有效组合（至少业务侧+资金侧）→ disabled
  - 满足条件 → enabled

自动化抓取（RPA 模拟弹窗）：
- Modal：标题 + progress bar + logs（黑底绿字，等宽字体）
- 完成：success toast + 文件自动进入文件池

---

### 4.4 对账控制台（Reconciliation Console / 向导）
参考：demo `#reconciliation`。

四阶段：
1) 数据映射确认：两个 mapping slot（业务侧/资金侧）
2) 智能预检：check list（待检查/检查中/通过）
3) 核心对账：console window + progress bar
4) 生成报告：成功卡 + 预览指标 + CTA 跳转结果页

交互细则：
- Stepper：active ring；completed 绿色
- Stage 切换：淡入 200–300ms
- 预检项状态：
  - checking：边框 `--primary-300`
  - passed：边框 `--success` + 轻绿底
- 核心对账进度：0 → 100%（300ms 递增过渡）

可访问性：
- 向导按钮明确 label（上一步/下一步/执行对账）
- Console window 应可复制内容（可选）

---

### 4.5 对账结果（Results）
参考：demo `#results`。

结构：
1) 顶部汇总卡 4 张
2) 三方金额对比表
3) 平台 tabs
4) 表格工具栏（搜索/状态筛选/导出）
5) 明细表格 + 分页
6) 异常汇总折叠面板

交互：
- Tab：active 下划线主题色
- 表格：hover `--primary-50`；异常行浅红
- 导出：按钮 loading + 完成 toast
- 折叠面板：箭头旋转 200ms；面板展开/收起

空/异常：
- 无结果：空态 + 引导“返回上传/重新对账”

## 5. 响应式与适配细则

### 5.1 1440（Large）
- stats-row 可固定 4 列
- 内容区 max-width 可适当放宽

### 5.2 1024（Desktop）
- upload 双栏可保持
- 复杂表格仍需支持横向滚动

### 5.3 768（Tablet）
- upload 变为单列（左侧源区在上，文件池在下）
- sidebar 改为 off-canvas
- topbar 搜索框隐藏

### 5.4 375（Mobile）
- 登录页仅表单
- 所有表格默认横滚（显示列优先级可定义）

## 6. 可访问性（A11y）规范补充

- 所有 icon button 必须有 `aria-label`
- focus-visible：不要移除 outline，使用 ring 替代
- 表格：th 语义正确；分页按钮可键盘操作
- 动效：尊重 `prefers-reduced-motion`（禁用进度条/条形动画/slideIn）
